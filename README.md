## Gestor de Horários (PWA)

Projeto desenvolvido em **React + Vite**, utilizando **Firebase (Auth, Firestore, Analytics)** e configurado como **Progressive Web App (PWA)**.

## Funcionalidades
- **Autenticação (Firebase Auth):**
  - Cadastro de novos usuários
  - Login com e-mail e senha
  - Logout seguro
- **Gestão de tarefas diárias:**
  - Criar tarefa com título e horário
  - Marcar tarefa como concluída/não concluída
  - Excluir tarefa
  - Resumo de tarefas concluídas do dia
- **Telas implementadas:**
  - Tela de **Login**
  - Tela de **Registro**
  - Tela **Home** (tarefas)
  - Tela de **Perfil** (dados do usuário + resumo do dia)
- **Progressive Web App (PWA):**
  - Suporte a instalação em desktop e mobile
  - Service Worker com cache offline
- **Firebase Analytics:**
  - Eventos de login, cadastro, criação, conclusão e exclusão de tarefas
